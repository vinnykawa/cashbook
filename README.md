# CashBook

CashBook is a legacy Android app for recording accounts and transactions.

## Project facts

- Android application module: `app`
- Application ID: `com.vmk.cashbook`
- Launcher activity: `com.nodem.cashbook.Login`
- SDK levels in `app/build.gradle`: compile SDK 29, min SDK 16, target SDK 29
- Build tooling in the repository: Android Gradle Plugin 4.0.0 and Gradle wrapper 6.1.1
- No product flavors are declared.
